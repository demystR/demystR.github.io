# demystR.github.io

The homepage for the [demystR](https://demystr.github.io) book series.

It is a single static page, `index.html`. To mark a book as published, set its `url` and `status` in the `BOOKS` list near the bottom of the file: `"read"` for a finished book, `"progress"` for one that is live but still being written, `"coming"` for one that is not live yet.
